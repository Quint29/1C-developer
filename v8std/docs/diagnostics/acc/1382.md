# В качестве объекта переадресации из гиперссылки "См. ..." указана процедура (функция), расположенная вне области "ПрограммныйИнтерфейс". (ACC 1382)

- Код АПК: `1382`
- Критичность АПК: `Рекомендация`

## Описание диагностики

В качестве объекта переадресации из гиперссылки "См. ..." указана процедура (функция), расположенная вне области "ПрограммныйИнтерфейс".
