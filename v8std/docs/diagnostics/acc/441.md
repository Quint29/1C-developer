# Отсутствует удаление временного файла после использования. (ACC 441)

- Код АПК: `441`
- Критичность АПК: `Обязательно`
- Прогнозируемое время исправления: `10 мин.`

## Описание диагностики

Отсутствует удаление временного файла после использования.
